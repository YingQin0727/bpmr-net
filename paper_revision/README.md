# MTCOMM major-revision execution

Revision-only code belongs under `paper_revision/`; generated artifacts belong
under `outputs/revision_mtcomm_2026/`. The submitted implementation under
`src/bpmr_net/` and the paper reproduction workflow under
`paper_reproduction/` are frozen.

The R1 pilot requires the frozen final-v1 registries, registered sparse-plane
manifests and plane store, baseline archive, source B0 checkpoints, and the
legacy reconstruction runtime. These inputs are external research data and are
never regenerated from dense truth.
