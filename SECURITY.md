# Security policy

## Supported versions

The latest tagged release is supported. The current `main` branch is a
development snapshot.

## Reporting a vulnerability

Use GitHub private vulnerability reporting when available, or contact the
repository maintainers privately. Do not include credentials, private dataset
URLs, access tokens, unpublished checkpoints, or personal information in a
public issue.

If a secret is committed, revoke or rotate it immediately before rewriting Git
history. History rewriting alone does not invalidate an exposed credential.
